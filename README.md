## Getting Started

Clone the repository:

```bash
git clone YOUR_PORTFOLIO_REPOSITORY_URL
```

Go to the project directory:

```bash
cd your-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
